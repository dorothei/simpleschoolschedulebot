# Simple School Schedule Bot for Telegram
This bot was my school project. Bot simply displays school lessons schedule, that's all.

# How to install?
Before this instalation create your bot in @BotFather.

1. Download all files
2.  Create a new folder
3. Unarchive all files in this folder
4. In config.py change bot token for yours in 11 line.
5. Open Terminal/Cmd
6. Enter "cd 'PATH:/TO/YOUR/FOLDER'" and python bot.py

# Command List
/start (alias /help, /помощь, /расписание, /старт) - displays school lessons schedule.

/timetable (alias /звонок, /звонки, /расписаниезвонков) - displays school bell timetable.
